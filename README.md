Простой веб-сервер для управления задачами, написанный на Go. Позволяет создавать задачи, отмечать их выполненными, настраивать повторения и искать по списку. Все данные хранятся в SQLite, интерфейс — обычный HTML/JS, ничего лишнего.

  # Что умеет
Cоздание, просмотр, редактирование, удаление
Отметка «выполнено» и автоматический расчёт следующей даты для периодических задач
Поиск по названию и описанию

  # Задания со звёздочкой
Аутентификация по паролю из переменной окружения TODO_PASSWORD
Защита API через JWT-токены (срок действия 8 часов)
Dockerfile для удобной сборки и запуска в контейнере

  # Запуск локально
Требования
Go 1.25 или новее
SQLite (подключается как файл, отдельный сервер не нужен)

Быстрый старт
Из корня проекта
    go run .
Сервер поднимется на порту 7540, база создастся как scheduler.db в текущей папке.
Открывайте в браузере: http://localhost:7540/
При заданной переменной TODO_PASSWORD появится страница входа:
http://localhost:7540/login.html

Переменные окружения (опционально)
Переменная                   Зачем                           По умолчанию
TODO_PORT             Порт HTTP-сервера                         7540
TODO_DBFILE         Путь к файлу базы SQLite                  scheduler.db
TODO_PASSWORD       Пароль для входа. Если не задан — аутентификация отключена

Пример запуска с настройками в PowerShell:
$env:TODO_PORT = "7540"
$env:TODO_DBFILE = ".\scheduler.db"
$env:TODO_PASSWORD = "my-secure-pass"
go run .

  # Запуск тестов
Тесты находятся в папке ./tests и проверяют API «вживую», поэтому сервер должен быть запущен.
1.Запустите сервер (порт и база должны совпадать с настройками тестов)
2.Откройте tests/settings.go и проверьте:
Port = 7540                    // должен совпадать с TODO_PORT
DBFile = "../scheduler.db"     // путь к той же базе
FullNextDate = true            // включать проверку сложных правил повторения
Search = true                  // включать тесты поиска
Token = ""                     // оставить пустым, если пароля нет
3.Если сервер с паролем — сначала получите токен:
curl -X POST http://localhost:7540/api/signin \
  -H "Content-Type: application/json" \
  -d '{"password":"ваш-пароль"}'
Ответ будет примерно такой: {"token":"eyJhbGciOi..."}.
Скопируйте значение токена и вставьте в tests/settings.go:   `Token = "eyJhbGciOi..."`
4.Запустите тесты:
go test ./tests -v

  # Docker
Сборка образа
в powershell -> docker build -t final-scheduler .
Запуск контейнера
в powershell
docker run --rm -p 7540:7540 `
  -v "${PWD}\data:/data" `
  -e TODO_PASSWORD=111 `
  final-scheduler

База SQLite будет сохраняться в папку ./data на хосте (чтобы не потерять данные при перезапуске)
Если аутентификация не нужна — просто уберите -e TODO_PASSWORD=...
